# Security policy

Spott handles account, event, and attendee information. Never include production records, credentials, or tokens in a public issue or reproduction.

If private vulnerability reporting is enabled for this repository, use **Report a vulnerability** in GitHub's Security tab. Otherwise, contact the repository owner through the public GitHub profile. Include the affected version, impact, and a minimal reproduction using synthetic data.

There is no published response-time guarantee. Revoke exposed Clerk, Convex, Gemini, and Unsplash credentials, then rotate them in each provider and deployment environment.
